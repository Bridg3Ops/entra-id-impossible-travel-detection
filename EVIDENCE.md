## Privacy review before publication

Remove tenant/subscription/workspace identifiers, account names, UPNs, email addresses, object/device/session/correlation IDs, public and private source IPs, tokens, precise locations and sensitive browser URLs. Inspect images, file metadata, hidden spreadsheet sheets and document properties as well as visible text. Use synthetic labels such as `account-A` and documentation-only values; keep any re-identification mapping private. Remove identifiers irreversibly from screenshots, rather than covering text with reversible overlays.

Do not commit raw exports. Review staged content and image pixels before uploading. If sensitive material is accidentally published, deleting the current file does not remove Git history; follow the service's sensitive-data removal process and rotate any exposed credentials.
